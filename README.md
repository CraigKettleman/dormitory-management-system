# 宿舍管理系统

数据结构课程设计项目 —— 基于 C++ 实现的宿舍信息管理系统。

## 功能概览

| 模块 | 功能 | 实现 |
|------|------|------|
| 信息管理 | 增加、删除、修改、显示 | 动态数组 + 线性查找 |
| 信息查找 | 顺序查找、折半查找、分块查找 | 三种查找算法 |
| 信息排序 | 冒泡排序、快速排序、直接插入排序 | 三种排序算法 |
| 数据持久化 | 启动自动加载、手动/退出保存 | 文本文件读写 |

## 快速开始

```bash
# 编译
make

# 运行
./dormitory

# 清理构建产物
make clean
```

## 数据格式

`data.txt` 使用 `|` 分隔字段，每行一条记录：

```
学号|姓名|性别|楼号|房间号|床位号|联系电话|专业
```

示例：
```
2024001|张三|男|A|101|1|13800001111|计算机科学
```

## 算法说明

### 查找

| 算法 | 用途 | 时间复杂度 |
|------|------|-----------|
| 顺序查找 | 按任意字段查找 | O(n) |
| 折半查找 | 按学号精确查找（需先排序） | O(log n) |
| 分块查找 | 按楼号分块查找 | O(√n) |

### 排序

| 算法 | 排序依据 | 时间复杂度 |
|------|---------|-----------|
| 冒泡排序 | 学号（升序） | O(n²) |
| 快速排序 | 姓名（升序） | O(n log n) |
| 直接插入排序 | 楼号 + 房间号 | O(n²) |
