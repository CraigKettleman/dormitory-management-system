# 题目七：宿舍管理系统

## 一、设计思想

### 1.1 问题分析

宿舍管理系统需要管理学生的基本住宿信息，包括学号、姓名、性别、宿舍楼号、房间号、床位号、联系电话和专业院系。系统需要实现信息的增加、删除、修改、查找和排序功能。

### 1.2 数据结构设计

采用**动态数组**作为主要数据结构，存储学生信息：

```cpp
struct Student {
    char id[20];        // 学号（唯一标识）
    char name[30];      // 姓名
    char gender[5];     // 性别
    char building[10];  // 宿舍楼号
    char room[10];      // 房间号
    char bed[5];        // 床位号
    char phone[15];     // 联系电话
    char major[30];     // 专业/院系
};

struct DormSystem {
    Student* students;  // 动态数组指针
    int count;          // 当前记录数
    int capacity;       // 数组容量
};
```

**选择动态数组的原因：**
- 支持随机访问，便于实现折半查找等算法
- 内存连续存储，缓存友好
- 容量不足时可动态扩展（2倍扩容）
- 适合课程设计中对线性结构的要求

### 1.3 系统架构

系统采用模块化设计，分为以下层次：

```
├── 数据层：student.h（数据结构定义）
├── 持久层：fileio.h/cpp（文件读写）
├── 算法层：search.h/cpp（查找算法）、sort.h/cpp（排序算法）
├── 表示层：ui.h/cpp（菜单界面、增删改操作）
└── 控制层：main.cpp（主程序入口）
```

## 二、算法设计

### 2.1 查找算法

#### （1）顺序查找

**算法思想：** 从数组第一个元素开始，逐个比较关键字，直到找到匹配元素或遍历整个数组。

**时间复杂度：** O(n)

**适用场景：** 可按任意字段（学号、姓名、楼号等）查找，通用性强。

```cpp
int sequentialSearch(DormSystem& sys, int field, const char* keyword, int* matchingIndices) {
    int matchCount = 0;
    for (int i = 0; i < sys.count; i++) {
        const char* value = NULL;
        switch (field) {
            case SEARCH_BY_ID:       value = sys.students[i].id; break;
            case SEARCH_BY_NAME:     value = sys.students[i].name; break;
            // ... 其他字段
        }
        if (value && strcmp(value, keyword) == 0) {
            matchingIndices[matchCount++] = i;
        }
    }
    return matchCount;
}
```

#### （2）折半查找（二分查找）

**算法思想：** 在有序数组中，取中间元素与目标比较，若相等则返回；若目标小于中间元素，在左半部分继续查找；否则在右半部分继续查找。

**时间复杂度：** O(log n)

**前提条件：** 数组必须按学号排序。

```cpp
int binarySearchById(DormSystem& sys, const char* id) {
    ensureSortedById(sys);  // 确保数组有序
    int low = 0, high = sys.count - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        int cmp = strcmp(sys.students[mid].id, id);
        if (cmp == 0) return mid;
        else if (cmp < 0) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

#### （3）分块查找

**算法思想：** 将数据分成若干块，建立索引表。先在索引表中确定目标所在的块，再在块内顺序查找。

**时间复杂度：** O(√n)

**实现步骤：**
1. 按楼号排序数组
2. 将数组分为 √n 个块，每块记录最大楼号
3. 先在索引表中查找目标楼号所属块
4. 在该块内顺序查找

```cpp
int blockSearchByBuilding(DormSystem& sys, const char* building) {
    // 按楼号排序
    // ...

    int blockSize = (int)(sqrt((double)sys.count));
    int blockCount = (sys.count + blockSize - 1) / blockSize;

    for (int b = 0; b < blockCount; b++) {
        int start = b * blockSize;
        int end = min(start + blockSize, sys.count);

        if (strcmp(building, sys.students[end - 1].building) <= 0) {
            for (int i = start; i < end; i++) {
                if (strcmp(sys.students[i].building, building) == 0)
                    return i;
            }
        }
    }
    return -1;
}
```

### 2.2 排序算法

#### （1）冒泡排序

**算法思想：** 相邻元素两两比较，将较大（或较小）的元素向后移动，每轮将一个最值"冒泡"到末尾。

**时间复杂度：** O(n²)（最好情况O(n)）

**优化：** 加入标志位，若某轮无交换则提前结束。

```cpp
void bubbleSortById(DormSystem& sys) {
    for (int i = 0; i < sys.count - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < sys.count - 1 - i; j++) {
            if (strcmp(sys.students[j].id, sys.students[j + 1].id) > 0) {
                Student temp = sys.students[j];
                sys.students[j] = sys.students[j + 1];
                sys.students[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;  // 无交换，已有序
    }
}
```

#### （2）快速排序

**算法思想：** 选择一个基准元素（pivot），将数组分为两部分：小于基准的在左边，大于基准的在右边，然后递归排序两部分。

**时间复杂度：** 平均O(n log n)，最坏O(n²)

**优化：** 采用三数取中法选择基准，小数组切换为插入排序。

```cpp
static int partitionByName(Student* arr, int low, int high) {
    int mid = (low + high) / 2;
    // 三数取中
    if (strcmp(arr[low].name, arr[mid].name) > 0) swap(arr[low], arr[mid]);
    if (strcmp(arr[low].name, arr[high].name) > 0) swap(arr[low], arr[high]);
    if (strcmp(arr[mid].name, arr[high].name) > 0) swap(arr[mid], arr[high]);

    Student pivot = arr[high - 1];
    int i = low, j = high - 1;
    while (true) {
        while (strcmp(arr[++i].name, pivot.name) < 0) {}
        while (strcmp(arr[--j].name, pivot.name) > 0) {}
        if (i < j) swap(arr[i], arr[j]);
        else break;
    }
    swap(arr[i], arr[high - 1]);
    return i;
}
```

#### （3）直接插入排序

**算法思想：** 将数组分为有序区和无序区，每次从无序区取一个元素插入到有序区的正确位置。

**时间复杂度：** O(n²)（最好情况O(n)）

**特点：** 稳定排序，对小规模或基本有序的数据效率高。

```cpp
void insertionSortByBuildingRoom(DormSystem& sys) {
    for (int i = 1; i < sys.count; i++) {
        Student key = sys.students[i];
        int j = i - 1;
        while (j >= 0 && compareBuildingRoom(sys.students[j], key) > 0) {
            sys.students[j + 1] = sys.students[j];
            j--;
        }
        sys.students[j + 1] = key;
    }
}
```

### 2.3 增删改操作

#### 增加记录
1. 检查数组容量，必要时扩容（2倍）
2. 输入各字段信息
3. 验证学号唯一性
4. 追加到数组末尾

#### 删除记录
1. 按学号查找目标记录
2. 确认删除
3. 将后续元素依次前移
4. 记录数减一

#### 修改记录
1. 按学号查找目标记录
2. 显示当前信息
3. 逐字段提示输入新值（回车跳过）
4. 更新修改的字段
